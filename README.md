## 反復（忘れないための仕組み）

- 1問ごとに記録。正解すると次回までの間隔が 1→3→7→14→30→60→120日 と伸び、間違えると 0 に戻る（翌日また出る）。
- 「苦手」= 2回以上間違えた、または直近4回で2回以上間違えた問題。ホームに一覧、「苦手だけ」ボタンで集中練習。
- セッション内: 間違えた問題は3問後に再出題、2回連続正解するまで終わらない。
- きょうの練習 = 期限の来た復習（全級） → 苦手 → 新しい問題（既定15問/日、設定で変更）。
- 新しい問題の順: 使用頻度の高い漢字から、漢字ごとに「読み2語・書き2語・筆順・画数・部首・送り仮名・音訓・同音」のまとまりで。全漢字を一巡後に残りの語。語彙問題は8問に1問差しこむ。
- 定着 = 復習間隔が14日以上。漢字表で ◎定着／○学習中／🔥苦手。

## 子ども向けUI（2026-10-13 実機フィードバック対応）

- 文中の対象語以外の漢字にはふりがな（設定で「今の級だけ」「なし」に変更可）。問題文・分野名・ボタンもルビ付き。
- 読みの答えはアプリ内の50音キーボード（IME変換なし）。゛゜小ー と ⌫ あり。設定で端末キーボード／四択にも変更可。
- 手書き欄とシート全体で長押し選択・コールアウトを無効化。

## 模擬テスト

級ごとの分野内訳（TEST_PLAN）で約50〜60問。合格ラインは 10〜8級 80%、7級〜2級 70%（漢検の基準に合わせた参考値、公式ではない）。結果は分野別正答率つきで保存、間違いは反復キューへ。

## データの作り方（tools/）

```bash
python3 tools/build_kanji.py   # kanji.js（学年・読み・画数・部首）+ strokes.js（書き順）
python3 tools/build_words.py   # words.js（頻出語）+ sentences.js（ふりがな付き例文）
```
入力: KANJIDIC2, KanjiVG, JMdict_e, Tatoeba jpn_transcriptions（scratchpad の src/ に取得済み。再取得先はスクリプト冒頭参照）。
子ども向けに不適切な語は BLOCK_SUB で除外。例文は辞書の読みと文中の読みが一致するものだけ採用。

## 出典とライセンス

学年配当: 文部科学省 学年別漢字配当表（2020年版、Wikipedia経由）。読み: 文化庁 常用漢字表。画数・部首: KANJIDIC2（EDRDG, CC BY-SA 4.0）。書き順: KanjiVG（Ulrich Apel, CC BY-SA 3.0）。熟語: JMdict（EDRDG, CC BY-SA 4.0）。例文: Tatoeba（CC BY 2.0 FR）。

## 既知の限界・今後

- 対義語・類義語・四字熟語・熟語の構成は手作成で各50〜100件。級が上がるほど薄いので追加が必要。
- 部首は康熙分類。漢検の分類と一部ずれる字がある。
- 例文は Tatoeba 由来で大人向けの文体が混じる。子どもが読みにくい文は今後差し替え。
- 4級〜2級の級別分割、準1級・1級。
- 手書き認識は無し（自己判定）。
